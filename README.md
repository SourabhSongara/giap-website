🌐 Global Internal Auditor Program (GIAP) – Web Application
📌 Overview

The Global Internal Auditor Program (GIAP) Web Application is a responsive and user-friendly website designed to present program details, objectives, curriculum, and enrollment information in a clear and structured manner.

This project focuses on delivering a modern UI, seamless navigation, and optimized performance to enhance user experience across all devices.

🚀 Features
✅ Fully responsive design (Mobile, Tablet, Desktop)
✅ Clean and modern user interface
✅ Intuitive navigation and structured content
✅ SEO-friendly layout
✅ Fast loading and performance optimized
✅ Cross-browser compatibility (Chrome, Edge, Firefox)

HTML5
CSS3
JavaScript
